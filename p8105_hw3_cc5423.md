# Problem 1

Loading dataset:

``` r
data("ny_noaa")
```

This dataset has 2595176 observations and 7 variables. It is describing
precipitation and temperature across several weather stations. There are
3387623 missing values across the whole dataset, which is quite a bit.
The variables include the following:

- `id`: station id
- `date`: date in YYYY-MM-DD format
- `prcp`: precipitation in tenth of mm
- `snow`: snowfall in mm
- `snwd`: snow depth in mm
- `tmax`: max temperature in tenth of degrees C
- `tmin`: min temperature in tenth of degrees C

Data cleaning:

``` r
ny_noaa =
  ny_noaa |> 
  mutate(month = lubridate::month(date), year = lubridate::year(date), day = lubridate::day(date),
         prcp = prcp/100, snow = snow/10, snwd = snwd/10, 
         tmax = as.numeric(tmax), tmin = as.numeric(tmin),
         tmax = tmax/10, tmin = tmin/10)
```

- Separate `date` variable into `month`, `day`, `year` variables
- Converting `prcp`, `snow`, and `snwd` into centimeters
- Converting `tmax` and `tmin` from character to numeric
- Converting `tmax` and `tmin` from tenth of degrees C into degrees C
